## Звіт до лабораторної роботи №30**
#### Тема: Написання юніт-тестів з xUnit
#### Мета: Навчитися писати юніт-тести для власного коду за допомогою xUnit, використовуючи різні типи assertion та параметризовані тести.

---

### **Хід роботи**

1. **Створення проєктів**
   Було створено основний проєкт `lab30vN` та тестовий проєкт `lab30vN.Tests` за допомогою команд:

```
dotnet new xunit -n lab30vN.Tests
dotnet add lab30vN.Tests reference lab30vN
```

2. **Реалізація бізнес-логіки**
   У основному проєкті було реалізовано клас `MathHelper`, який містить наступні методи:

* `IsPrime(int number)` — перевірка, чи є число простим
* `Factorial(int n)` — обчислення факторіалу числа
* `Fibonacci(int n)` — обчислення n-го числа Фібоначчі
* `GCD(int a, int b)` — знаходження найбільшого спільного дільника

3. **Написання юніт-тестів**
   У тестовому проєкті було створено набір тестів із використанням фреймворку xUnit. Було реалізовано більше 10 тестів із застосуванням атрибутів `[Fact]` та `[Theory]`.

**Приклади тестових сценаріїв:**

* **IsPrime:**

  * Перевірка простого числа (наприклад, 7)
  * Перевірка складеного числа (наприклад, 8)
  * Перевірка граничних значень (0, 1, від’ємні числа)

* **Factorial:**

  * Обчислення факторіалу для додатних чисел
  * Перевірка факторіалу 0 (очікується 1)
  * Обробка від’ємних чисел (викидання винятку)

* **Fibonacci:**

  * Перевірка перших чисел послідовності
  * Перевірка граничних значень (0, 1)
  * Обробка некоректних значень

* **GCD:**

  * Знаходження НСД для різних пар чисел
  * Перевірка випадків із нулем
  * Перевірка від’ємних значень

4. **Використані assertion:**

* `Assert.Equal()`
* `Assert.True()` / `Assert.False()`
* `Assert.Throws<Exception>()`

5. **Запуск тестів**
   Тести були успішно виконані за допомогою команди:

```
dotnet test
```

Усі тести пройшли успішно, що підтверджує коректність реалізованої логіки.
